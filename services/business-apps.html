Featured project

An online yoga booking platform

Class sign-ups, waivers, Zoom links and reminders were all handled by hand. Now students sign up themselves and the app handles the rest.

What it does

  • Self-service sign-up and schedule management
  • Liability waiver capture
  • Waitlists that know class capacity and promote students automatically
  • Zoom sessions created automatically for each class
  • Email reminders before every scheduled class
  • An admin console to change the class schedule, handle cancellations and manage sign-ups
  • A reporting dashboard showing sign-ups per class, trends and averages
  • Editable text on the public website, so content updates never require touching code
